# Employee Workforce Exploratory Data Analysis

An end-to-end Exploratory Data Analysis project focused on understanding employee demographics, salaries, departments, experience, performance, and working arrangements.

## Project Objectives

- Understand the structure and quality of the employee dataset.
- Detect and handle missing values.
- Identify and remove duplicate records.
- Clean inconsistent categorical values.
- Detect and evaluate numerical outliers.
- Perform univariate, bivariate, and multivariate analysis.
- Generate meaningful workforce insights and recommendations.

## Tools and Technologies

## EDA Workflow

1. Define the business problem
2. Load and inspect the dataset
3. Understand columns and data types
4. Detect missing and duplicate values
5. Clean inconsistent data
6. Detect and handle outliers
7. Perform univariate analysis
8. Perform bivariate analysis
9. Perform multivariate analysis
10. Generate insights and recommendations

## 📄 Dataset

This project uses a synthetic employee workforce dataset created for learning and portfolio purposes. The dataset includes intentionally introduced data quality issues such as missing values, duplicate records, inconsistent categories, outliers, invalid dates, and invalid email formats to demonstrate real-world data cleaning and analysis techniques.
