# Employee Workforce Exploratory Data Analysis

An end-to-end Exploratory Data Analysis project focused on understanding employee demographics, salaries, departments, experience, performance, and working arrangements.

## Project Objectives

- Understand the structure and quality of the employee dataset.
- Detect and handle missing values.
- Identify and remove duplicate records.
- Clean inconsistent categorical values.
- Detect and evaluate numerical outliers.
- Perform univariate, bivariate, and multivariate analysis.
- Generate meaningful workforce insights and recommendations.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook
